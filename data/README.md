# Données locales

Les datasets réels ne sont pas présents dans ce dépôt. Ajouter uniquement les fichiers autorisés par l'enseignant et leur licence; les CSV bruts, holdouts et batchs sont ignorés par Git. Compléter les configurations locales depuis les fichiers `*.example.yaml`, puis exécuter `scripts/preflight_data.py` avant tout entraînement.

Ne jamais placer ici de credentials, données personnelles ou fichiers dont la licence interdit le stockage/partage. Conserver l'URL, la version, la licence, l'approbation et les décisions de cible/split dans la provenance locale; remettre les métadonnées non sensibles séparément après validation.
